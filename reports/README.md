System Architecture

The architecture of the system follows this flow:

User → Frontend → Backend → ML Model → Prediction Result

Components

- Frontend: User interface for entering news content
- Backend: Handles API requests and processing
- ML Model: Predicts whether news is fake or real
- Output: Displays prediction result

Sequence Diagram

1. User enters news article text
2. Frontend sends request to backend
3. Backend processes the input
4. Machine learning model predicts result
5. Backend returns prediction
6. Frontend displays result
