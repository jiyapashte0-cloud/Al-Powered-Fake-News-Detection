AI Fake News Detection

This folder contains the complete source code for the AI Fake News Detection project.

Folder Structure

src/

- frontend/
- backend/
- model/

Frontend

The frontend is responsible for user interaction.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- User-friendly interface
- News text input
- Prediction result display

Backend

The backend handles request processing and communication between frontend and machine learning model.

Technologies Used

- Python
- Flask

Responsibilities

- Receive input from frontend
- Process API requests
- Send data to ML model
- Return prediction result

Machine Learning Model

The machine learning model classifies news as Fake or Real.

Technologies Used

- Scikit-learn
- Pandas
- NumPy

Function

- Analyze news text
- Predict whether news is fake or real

Workflow

1. User enters news text
2. Frontend sends data to backend
3. Backend processes request
4. ML model predicts result
5. Prediction shown to user

Output

The system outputs:

- Fake News
  OR
- Real News
